# Research Cycle

[English](README.md)

Переносимый навык: выбирать эксперименты, анализировать результаты, менять план и
проверять выводы. Цель, методы и ресурсы задаёт пользователь. Цель по метрике и общий
срок могут быть единственными ресурсными ограничениями.

**Экспериментальная v2.0.0-rc.2.** Адаптивный пилот Cheng достиг mean validation
macro-F1≥0,92 на трёх новых seeds примерно за2ч29м.

| Исторический запуск | Победитель | Mean validation F1 | Mean закрытый test F1 |
|---|---|---:|---:|
| Без навыка | DenseNet121 | 0,902062 | 0,878772 |
| Адаптивный с навыком | DenseNet121 | **0,932217** | **0,886990** |

Разница на test — **+0,822 процентного пункта**. Это сравнение разных процессов,
а не контролируемая проверка одного навыка: различались эпохи, рецепты, остановка
и учёт. Интервал по пациентам включает ноль; причинный прирост качества и экономия
вычислений/токенов не установлены.

## Применение

1. Скачать [релиз](https://github.com/AegonnI/research-cycle/releases/tag/v2.0.0-rc.2)
   или передать агенту `skills/research-cycle/`.
2. Задать данные/методы, метрику, подтверждение и остановку. Есть
   [адаптивный промпт](templates/ADAPTIVE_GOAL_TEMPLATE.ru.md) и
   [полный контракт](templates/RESEARCH_TASK_TEMPLATE.ru.md).
3. Модели, параметры, эпохи и следующие опыты выбирает агент. Квоты моделей,
   лимиты попыток/compute и фиксированные резервы нужны только при явном задании.
4. Для Hermes явно вызвать `/goal`, обеспечить внешний срок и проверку результатов.
   Сам Markdown не включает Goal и не создаёт инструменты исполнения.

SKILL.md — английский; [guide.ru.md](skills/research-cycle/references/guide.ru.md) —
русский эквивалент. Адаптивный маршрут двуязычный. Читать нужный режим и язык.

## Исполнение

- **Адаптивный исполнитель:** [пример Cheng](examples/cheng-adaptive/README.md),
  Linux/WSL и существующий CUDA Python. Проверяет попытки, позволяет увеличить
  таймаут повтора, фиксирует рецепт до трёх новых seeds и закрывает задачу по цели/сроку.
  Исходники совпадают с проверенным пилотом; добавлен публичный скрипт подготовки.
- **Отдельный SQLite-помощник:** `memory.py` для контрактов с лимитами попыток/compute.
  Он учитывает доказательства, но процессы не останавливает. Для wall-only задачи
  использовать адаптивный исполнитель, не придумывая дополнительные лимиты.

ZIP навыка содержит инструкции, помощник и шаблоны. ZIP примера дополнительно содержит
исполнитель, тесты и агрегированные метрики. Изображения, веса, базы экспериментов,
учётные данные и личный манифест не публикуются.

## Проверка и сборка

```sh
python -m unittest discover -s tests -v
python scripts/build_release.py
```

Тесты проверяют программу, не эффективность навыка. Глобальная установка пакетов
навыку не нужна; вычислительные библиотеки определяет задача. Лицензия MIT.
