# Research Cycle

Универсальный навык организации вычислительных исследований для существующей ИИ-агентской среды. Он задаёт работу с целью, гипотезами, экспериментами, ограничениями и выводами. SQLite-помощник сохраняет историю исследования и ссылки на доказательства.

**v1.0.0 — экспериментальный снимок первой проверенной версии.** В этом выпуске сохранена реализация, использованная в пилоте, включая известные ограничения. Улучшение навыка и новый запуск с нативным `/goal` запланированы на следующий этап.

## Подключение

Скачайте ZIP из [релизов](https://github.com/AegonnI/research-cycle/releases) либо используйте папку `skills/research-cycle/` из репозитория. Подключите её способом, поддерживаемым вашей средой, или явно поручите агенту прочитать `SKILL.md` и связанные материалы.

Заполните [шаблон цели](templates/RESEARCH_GOAL_TEMPLATE.md): вопрос, метрика, условия подтверждения, входные данные, разрешённые изменения и лимиты. Начинайте исследование в отдельной папке. Для чистого сравнения не передавайте новому исследователю результаты контрольного запуска.

Если среда поддерживает `/goal`, эту команду нужно вызвать явно. Наличие шаблона с командой само по себе не включает goal-режим. В первом пилоте команда не вызывалась.

Навык использует возможности среды: поиск, файлы, выполнение кода и вычислительные ресурсы. SQLite-помощнику нужны Python 3.10+ и стандартная библиотека; тяжёлые зависимости устанавливаются только при необходимости конкретной задачи и по правилам пользователя.

## Что показал пилот

Агент с навыком достиг заданного validation-порога и завершил необходимые повторы. Он не обязан был расходовать весь оставшийся бюджет на дальнейший поиск. SQLite действительно использовалась, неудачи учитывались, финальное решение фиксировалось до теста.

Улучшение качества на тесте и сокращение вычислительных затрат пока не показаны. Два запуска различались рецептом обучения, seeds, исходной подготовкой и целью остановки, поэтому они не доказывают причинный эффект навыка. Польза памяти после потери контекста и экономия токенов отдельно не проверялись.

## Известная ошибка

В v1.0.0 fingerprint учитывает все поля JSON конфигурации. Если там находится `run_id`, его переименование позволяет одинаковым научным настройкам получить другой fingerprint. До исправления необходимо вручную проверять повторы и отделять служебные имена от научных настроек. Ошибка задокументирована; исправление выйдет отдельной версией.

## Проверка и сборка

```sh
python -m unittest discover -s tests -v
python scripts/build_release.py
```

Тесты проверяют механику журнала, а не полезность навыка как исследовательской методологии. В публичный выпуск входят навык, шаблон, тесты, документация и агрегированный разбор. Данные пациентов, веса моделей, базы экспериментов, переписка и описание личной инфраструктуры не распространяются.
