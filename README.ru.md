# Research Cycle

[English](README.md)

Навык помогает ИИ-агенту организовать исследование: понять вопрос, изучить контекст,
выбрать подход, проверить результаты и подготовить выводы. Подходит для обзоров
литературы, анализа данных, симуляций и сравнения методов. Инструменты предоставляет
ваша агентская среда.

## Как начать

1. Передайте агенту папку [research-cycle](skills/research-cycle) с `SKILL.md` и справками
   либо подключите её как навык в своей среде. Если доступны только текстовые сообщения,
   передайте содержимое `SKILL.md` и нужных справок.
2. Скопируйте [запускающий промпт](templates/RESEARCH_GOAL_TEMPLATE.md).
3. В том же сообщении напишите задачу своими словами. Заполнять скобки не нужно.

Агент сам оформит рабочую постановку, кратко обозначит понимание и начнёт работу.
Если без уточнения нельзя продолжить, он задаст конкретный вопрос. Для обзора не
требуется придумывать числовую метрику или обучать модель.

Например, можно написать:

> У меня есть почасовые данные потребления электроэнергии в папке проекта. Хочу
> сравнить способы прогноза на сутки вперёд. Есть два часа, использовать только
> установленные библиотеки. Нужен отчёт на русском с честной проверкой качества.

Или:

> Подготовь обзор методов восстановления пропусков во временных рядах. Сравни
> предпосылки, ограничения и качество доступных доказательств. Обучение не требуется.

## Что полезно указать

Это подсказка, а не обязательная анкета:

- Что хотите узнать и какой результат получить.
- Какие файлы, данные или источники доступны.
- Как поймёте, что результат достаточен; метрику/порог — если они есть.
- Какие методы разрешены, что менять нельзя.
- Желаемый срок и другие действительно нужные ограничения.
- Где можно работать с файлами и какие инструменты/библиотеки уже доступны.
- Язык, формат и аудиторию отчёта.

Можно приложить манифест окружения. Для точной постановки остаётся
[необязательный шаблон](templates/RESEARCH_TASK_TEMPLATE.ru.md), который также может
заполнить сам агент. По умолчанию не навязываются SQLite, GPU, квоты моделей,
фиксированные резервы или конкретная платформа. Goal, поиск и технические таймеры
работают лишь при поддержке среды; Markdown их сам не создаёт.

## Проверка и сборка

```sh
python -m unittest discover -s tests -v
python scripts/build_release.py
```

Тесты проверяют вспомогательный код и согласованность опубликованных метрик.
Универсальность инструкции не означает доказанного качества во всех областях.
Данные, веса, личные настройки и учётные данные в пакет не входят. Лицензия MIT.

## Результаты выполненного пилота

Числа сохранены без изменений; они получены предыдущим адаптивным маршрутом на
стенде Cheng, а не новой редакцией свободного ввода.

| Исторический запуск | Победитель | Mean validation F1 | Mean закрытый test F1 |
|---|---|---:|---:|
| Без навыка | DenseNet121 | 0,902062 | 0,878772 |
| Адаптивный с навыком | DenseNet121 | **0,932217** | **0,886990** |

Разница test — **+0,822 процентного пункта**. Процессы различались по эпохам,
рецептам, остановке и учёту; интервал разницы по пациентам включает ноль.
Причинный прирост от самого навыка и экономия ресурсов не установлены.
