# Бесплатная модель для двух запусков

Проверка публичных источников: **02.11.2026**. Это рекомендация для пилота, не
результат измерения качества моделей на нашем исследовании.

Основной кандидат — **Step 3.7 Flash через бесплатный тариф Nous Portal**.
[Каталог Portal](https://portal.nousresearch.com/) показывает эту модель с ценой $0.00/1M;
Free допускает бесплатные модели и имеет стандартные ограничения. Разработчик модели
указывает поддержку агентов, включая Hermes, в
[официальном репозитории StepFun](https://github.com/stepfun-ai/Step-3.7-Flash).
Облачный вариант оставляет всю RTX 5060 Ti для обучения CNN. Нулевой тариф Portal
не означает, что прямой API StepFun бесплатен.

**Публичной гарантии квоты на два длинных ресерча нет.** Перед запуском войти в
Nous Portal через `hermes model` в каждом новом профиле, выбрать именно бесплатную
Step 3.7 Flash и сохранить фактически выданные ID/provider/revision. Не подставлять
непроверенный суффикс `:free`: названия провайдеров могут различаться. Проверить
доступную квоту аккаунта и короткий вызов инструмента. Предлагаемый потолок — до
300 запросов и 4 млн суммарных input+output tokens на условие, включая судью,
сжатие и повторы; это лимиты эксперимента, а не обещанная квота сервиса.
Если квота меньше, одинаково уменьшить оба бюджета до старта или выбрать локальный вариант.

Не включать платный fallback и случайный роутер моделей. При исчерпании квоты
зафиксировать остановку; переход на другую модель посреди пары нарушит сравнение.
Резервные модели/провайдеры могут также вызываться вспомогательными задачами Hermes:
проверить фактические маршруты судьи и сжатия контекста.

**Вариант без лимита API: локальная `qwen3.5:9b` через Ollama.**
[Карточка Ollama](https://ollama.com/library/qwen3.5:9b) отмечает поддержку tools;
основной Q4_K_M файл около 6.6 GB, дополнительно нужны память контекста и служебные
данные. [Официальная инструкция Hermes](https://hermes-agent.nousresearch.com/docs/guides/local-ollama-setup)
описывает custom endpoint `http://localhost:11434/v1`. Если модель уже есть —
использовать её; здесь ничего не скачивается и не устанавливается автоматически.
Это запасной вариант по доступности, не доказанная замена качеству облачной модели.
Начать с умеренного контекста, например 16–32k, и одинаковых параметров для обоих условий.
Чтобы не делить VRAM с обучением, обслуживать LLM на CPU либо выгружать её из GPU
до запуска обучения. Локальная модель медленнее; увеличить wall-бюджет сразу для обоих
условий, не меняя вычислительный бюджет CNN.

[OpenRouter free](https://openrouter.ai/docs/api_reference/limits) на аккаунте без
пополнения ограничен 50 запросами в сутки и 20 в минуту; судья тоже делает запросы.
Этого нельзя уверенно обещать для двух длительных сессий. Увеличение квоты после
покупки кредитов не отвечает условию «полностью бесплатно». Проверять ограничения
аккаунта перед стартом; не обходить их новыми аккаунтами.

Бесплатный веб-чат сам по себе не даёт Hermes бесплатный API. Истёкшие акции
не считать доступным ресурсом. При любой модели способность надёжно пользоваться
инструментами проверяется до исследований, без чтения навыка и датасета.
