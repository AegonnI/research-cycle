# Capabilities and limits / Возможности и ограничения

- The skill is instructions, not a standalone agent runtime. Search, files, code,
  native Goal and process deadlines depend on the host. Unsupported work is reported.
- Universal method does not mean universal validation. The published experimental
  evidence is a 2D MRI computational pilot; the new intake/general wording has not
  been evaluated in another full agent study or across all research domains.
- Qualitative reviews, numerical optimization and simulations need different designs
  and verification. No metric, quota, three-seed rule or storage backend is mandatory
  merely because an example used it.
- Natural-language intake can misinterpret ambiguous requests. Paths, numerical units,
  permissions and blocking contradictions must be checked. Unspecified permission
  is not permission to read unrelated projects or install dependencies.
- The SQLite helper requires explicit attempt/compute budgets. It verifies declarations
  and file hashes, not process termination, provider usage, metric truth or OS isolation.
- The historical adaptive executor, its fixed trainer and model space remain available
  in the preserved v2.0.0-rc.2 release. They are an optional domain-specific example.
- Hashes/journals do not protect against an OS administrator. Unknown LLM usage stays unknown.
- One historical run per condition, different recipes/epochs/goals/accounting and
  prior organizer use of test prevent a causal skill-effect claim. The conditional
  test-difference interval includes zero; token/compute savings are not established.
- Memory recovery and reliability across long/multi-domain studies need further evaluation.

Русский: навык переносим как методика, но не обещает инструментов и качества,
которых не обеспечивает среда или доказательства. Универсализация инструкции не
означает, что новые задачи уже экспериментально проверены. ТЗ определяет работы и критерии приёмки; фактические результаты и замечания оформляются в отчёте.
