# SQLite-память — без новых библиотек

Имеющийся Python запускает поставляемый `scripts/memory.py`. Команды и JSON-примеры
см. [memory.md](memory.md); CLI остаётся английским. Большие файлы хранятся рядом,
пути доказательств не могут выходить за папку базы.

Порядок: init → hypothesis → begin/finish для каждой попытки → finding →
checkpoint/snapshot → freeze → итоговая оценка/charge → audit → close.

Обязательны question, metric с key и direction (maximize/minimize), положительные
max_attempts (целое) и max_compute_seconds. final_evaluation_reserve_seconds —
резерв итогового inference. Обучение финалистов дополнительно резервирует контроллер.
Правила исследования и method_scope тоже входят в контракт.

Конфигурация: science — всё влияющее на результат; execution — имя/папка запуска.
Других верхних полей при такой форме нет. В science входят данные/split, хеши кода
и весов, preprocessing, архитектура, параметры, optimizer, seed, fidelity. Подпись
считает science и хеш контракта: переименование папки не обходит дубли.
В старой плоской форме игнорируются только верхние run_id, output_dir, output_path,
log_path, started_at. Не менять название этапа/код ради обхода дубликата.
Точный повтор — только после сбоя с --retry-reason. Успешный/работающий дубль запрещён.
Новый seed — повтор устойчивости, а не архитектура.

Завершённая попытка требует конечное числовое значение metric.key. При сбое метрика
может отсутствовать; фиктивный ноль недопустим. Доказательства/метрики хешируются.
Для меняющегося trainer сохранять отдельный неизменяемый снимок каждой версии.
Открытый резерв учитывается после перезапуска. Проверить процесс перед закрытием сбоя.
Перерасход сохраняется как budget_violation, блокирует новые запуски; после учёта
остатков закрыть invalid/stopped. charge учитывает вычисления вне обучения, но
таймаут не обеспечивает. Внешний timeout должен вмещать validation и очистку.

snapshot выдаёт расход/числа, открытые попытки, checkpoint, 20 последних гипотез,
10 выводов и 5 лидеров, выбранных SQLite. Без фильтра fidelity могут различаться:
это не итоговый рейтинг. Фильтр: snapshot --db research.sqlite --stage confirm.
Точка восстановления — JSON с next_action, reason, evidence_ids: [1], при необходимости
путями/остатками работ; максимум 12 000 символов. checkpoint --note next.json сохраняет
решения и ссылки, а не скрытые рассуждения. Для адресного чтения использовать show.

freeze сохраняет выбор с хешами до test и блокирует обучение. audit пересчитывает
хеши попыток/решения и завершает команду с ошибкой при изменении/пропаже/открытых
попытках. Он не доказывает правильность метрик и научную цель. close achieved требует
отдельной проверки всех критериев. Остальные статусы: budget_exhausted, inconclusive,
stopped, invalid.

База не останавливает процессы, не считает токены провайдера, не анализирует код сети,
не запрещает читать test или править SQLite напрямую. Для v2 создать новую базу;
автоматической миграции пилотов v1 нет.
